# Stride Circle feature map

The map covers the user-facing surfaces that must remain verifiable as the app changes.

- [Authentication](./authentication.md) covers sign-in and account creation.
- [Today](./today.md) covers the step-first home loop.
- [Circles](./circles.md) covers private and public circle setup.
- [Activity](./activity.md) covers native walk and run recording.
- [History](./history.md) covers saved steps and recorded activities.
- [Profile](./profile.md) covers the personal profile surface.

The web fallback can prove route rendering and browser-safe interactions. Firebase-backed flows require `app/.env` and a test account. Health and GPS flows require a native development build.
