# Profile

Route: `/profile` (opened from the Home profile surface)

Verify:

1. The user can view and edit their own display name and character/avatar selection.
2. The user can reach daily-goal settings and sign out.
3. Profile edits are scoped to the authenticated user.
4. Health permission recovery and privacy controls explain their current state without exposing health data to other users.

Current public-profile exposure is intentionally limited. Do not assume direct messaging, public user profiles, or a complete moderation UI exists.
