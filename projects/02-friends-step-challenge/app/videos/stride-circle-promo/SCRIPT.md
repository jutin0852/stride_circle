# Script — 20-second product promo

**Format:** 1920×1080 landscape  
**Audio:** No voiceover in this first pass; on-screen copy is timed as the message spine.  
**Tone:** Warm, confident, quietly energizing.

## On-screen copy

1. **0.0–4.1s — Hook** — “Move together.” / “Make everyday movement feel more social, more visible, and easier to return to.”
2. **4.1–9.0s — Personal proof** — “Your progress, in view.” / “Steps, goals, streaks, and history—without the noise.”
3. **9.1–14.0s — Social payoff** — “Find your circle.” / “Create a friendly challenge, compare progress, and keep each other going.”
4. **14.1–20.0s — Close** — “Make every walk count.” / “Your next step can be personal—and still move everyone forward.” / “Stride Circle. Move together.”

## Claim discipline

The copy is based on the current implemented surfaces: personal steps and goals on Home, personal progress and history on History, and circles plus circle standings on Circles. It intentionally avoids promising native health-provider behavior, rewards, or anti-cheat guarantees that are not proven by the saved UI evidence.
