# Duck components traced from the original sheet

Open index.html for side-by-side original-crop and vector-trace comparisons.

47 separate SVG files cover the component sections plus the eight face-expression references. The SVGs contain genuine editable paths, with no embedded PNG image. Source crop coordinates are in manifest.json. File names use the sheet's own left/right labels.

This is a first automated contour trace of the original pixels. The silhouettes come from the supplied image, not a freehand redraw. Transparent backgrounds and a flat palette replace the raster sheet's backdrop, shading and antialiasing. Outlines may retain small pixel steps and need smoothing in a vector editor. Small details, especially the rain/sleep marks and dark clothing details, deserve inspection at full size.

The head, body, wings, hands and beaks are independent files. A leg-and-shoe component is kept together as pictured; separate its ankle and shoe after import if needed. Color paths are named within each SVG, but they are not anatomical rig layers. Facial reference SVGs are complete facial designs rather than preassembled expression rigs. No Rive bones, pivots, timelines or state machines have been created for these assets.

The full character variants and sample poses were not included in the review package. They are pose references rather than independent rig components; unfinished trace attempts remain under unreviewed-pose-drafts and should not be imported as approved assets.

Import one SVG into Rive, inspect its paths and grouping, then assemble the neutral duck before setting pivots and animating. Preserve this source package for future cleanup.
